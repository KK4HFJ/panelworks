# PanelWorks Manual

Installing, designing, and programming PanelWorks panels.

A printable A4 copy of this whole manual is
**[PanelWorks-Manual.pdf](../PanelWorks-Manual.pdf)**.

## Contents

1. [Introduction](01-introduction.md): what PanelWorks is; forms, objects, properties, methods, events
2. [Installing](02-installing.md): Windows step by step, macOS, Linux, updating
3. [Your first panel](03-first-panel.md): a hands-on tutorial, click by click
4. [The Designer](04-designer.md): toolbox, properties, events, connections, Start and End
5. [The Code window](05-code-window.md): writing procedures, the syntax check, renaming
6. [Programming](06-programming.md): event procedures, properties, timers, threads, errors
7. [The form file](07-form-file.md): the JSON format, values, `${VAR}`
8. [MQTT](08-mqtt.md): subscribe, publish, mirror, the MQTT control
9. [Serial](09-serial.md): Arduinos, GPS units, radios. Includes a tutorial: switch an Arduino's LED from a panel
10. [n8n and webhooks](10-n8n-webhooks.md): workflows as event procedures
11. [Claude and MCP](11-claude-mcp.md): letting Claude drive and build panels
12. [Control reference](12-control-reference.md): every property, method and event
13. [Example panels](13-examples.md): what each example shows
14. [Troubleshooting](14-troubleshooting.md): problems and cures
15. [Coming from Visual Basic](15-coming-from-vb.md): VB6 to PanelWorks, side by side
16. [Phone view](16-phone-view.md): use any panel from a phone, safely
17. [Modbus and SNMP](17-modbus-snmp.md): PLCs, drives, meters, UPSes, PDUs and switches
18. [Alarms](18-alarms.md): limits, acknowledge, history, Telegram / n8n / MQTT notification
19. [Appendix](99-appendix.md): shortcuts, command line, signatures
